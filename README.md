# Meu Portfólio Pessoal

**Aluna:** Gabriely Cezário

## Descrição

Este projeto é meu portfólio pessoal, criado para apresentar um pouco sobre mim, meus estudos na área de Desenvolvimento de Sistemas, minhas habilidades e meus projetos publicados no GitHub.

## Tecnologias utilizadas

- HTML: estrutura da página.
- CSS: cores, espaçamentos e efeitos visuais.
- Bootstrap 5: menu responsivo, botões, cards e organização das seções.

## Como funciona o projeto

A página tem um menu que leva às seções Início, Perfil, Habilidades, Projetos e Contato. Na parte de projetos, os botões abrem os respectivos repositórios no GitHub. Na seção de contato, é possível clicar no e-mail para escrever uma mensagem ou acessar meu perfil no GitHub.

O Bootstrap ajuda o site a se adaptar a telas de celular e computador.

## Recurso novo adicionado

Incluí a seção **Minhas habilidades**, que apresenta as tecnologias que estou estudando. Também adicionei **efeitos de hover** nos blocos de habilidades e nos cards dos projetos.

## Arquivos do projeto

- `index.html`: conteúdo da página.
- `style.css`: estilos e efeitos visuais.
- `README.md`: explicação do projeto.
